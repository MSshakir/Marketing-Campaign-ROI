
# Marketing Campaign ROI Analysis

## About the Project
This project analyses marketing campaign performance using an interactive dashboard. It helps users understand campaign spending, revenue, return on investment (ROI), and conversion rates.

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- MySQL
- Power BI
- Excel

## Key Features
- Interactive dashboard
- CSV file upload
- Marketing channel filters
- ROI and revenue charts
- Campaign performance analysis
- Automatic marketing recommendations
- Downloadable analysis results

## Data Disclaimer
The built-in dataset contains simulated marketing data. Users can upload their own CSV files for analysis.

## How to Run
1. Install the required Python packages:
   `python -m pip install streamlit pandas plotly`
2. Run the application:
   `python -m streamlit run app.py`

## Project Purpose
Created as a Data Analyst portfolio project to demonstrate data analysis, visualization, and business reporting skills.
